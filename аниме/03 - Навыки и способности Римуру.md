# Навыки и способности Римуру (из субтитров)

**Важно:** это **не полный гайд по лайт-новелле**. Только то, что **звучит** в RU Crunchyroll-репликах Римуру и Великого мудреца/Рафаила.  
Полный список скиллов в каноне шире — здесь character-facing слой.

## Как у него устроена «система»

1. **Внутренний аналитик** — Великий мудрец → позже **Рафаил** (зовёт, просит анализ, доклад).  
2. **Поглощение / разбор** — «Хищник», желудок, анализ съеденного.  
3. **Эволюция навыков** — мудрец «запрашивает эволюцию», навыки «получены / изучены».  
4. **Имена** — даёт имена другим (сила + связь); сам несёт имя *Римуру Темпест*.

## Ядро (часто в диалогах)

| Имя в субтитрах | Роль по репликам | Примеры |
|---|---|---|
| **Великий мудрец** | Анализ, подсказки, «изучи», эволюция | «Великий мудрец, изучи.» · «давай анализ» |
| **Рафаил** (Владыка знаний) | Эволюция мудреца; зов в кризисе | «Рафаил! Как мне выкрутиться?!» · «Владыка знаний, Рафаил! Подсоби!» |
| **Хищник** | Особый навык: поглощать / разбирать | «Особый навык: Хищник!» · «поглоти … Хищником» · «Ух, Хищник — вещь!» |
| **Анализ** | Разбор веществ, существ, умений | «Проанализируешь растения…» · «Я его просто проанализировал» |
| **Безжалостный** | Особый навык (активация через мудреца) | «активировать особый навык Безжалостный?» |
| **Метаморфоз** | Связан с мудрецом/формой | «Великий мудрец преподносит Метаморфоз» |
| **Обжорство → Вельзевул** | Эволюция прожорливого навыка | «Обжорство эволюционировало в Вельзевула» |

## Что получает / использует (по упоминаниям)

Из реплик мудреца и Римуру (не полный перечень):

- **Водный клинок**, **Управление водой**, **Передвижение в воде**  
- **Стальная нить**  
- **Чёрное пламя** (экстра)  
- **Ядовитое дыхание**, **Тепловидение**, **Звериный нюх**  
- **Коммуникация**, **Устрашение**, **Раздвоение**  
- **Магическая защита**, **Быстрая / Бесконечная регенерация**  
- **Магическое чутьё**  
- Упоминания получения чужих/уникальных: **Узурпатор**, **Неизменность**, **Избранный**, **Кузнец богов** (контекст «дар»/чужой навык в сценах)  
- Пространственные эффекты: «Обнаружен эффект пространственного навыка», **Бесконечное заточение** (взаимодействие с Хищником)

## Не «кнопка», а привычки силы

- **Именование** — «Просто дать им имя — уже большое дело», «Гордо неси это имя…»  
- **Поглощение душ/сил** — мудрец объясняет условия навыков  
- **Маглементы / магия** — «накопленные маглементы, чтобы применить магию и навыки»  
- **Копия / изучение** после боя — «Все навыки Ифрита… изучены»

## Как Римуру *относится* к силе

1. Сначала **вау** («крутой навык»).  
2. Потом **эксперимент** («много чего попробовал и получил новые»).  
3. Потом **инструмент для людей/страны** (защита, стройка, переговоры с позиции силы).  
4. В кризисе — **зов Рафаила**, не соло-паника без системы.

## Ограничение источника

Субтитры **не** дают стабильной «таблицы всех скиллов на конец s3».  
Для Legion: важнее **паттерн** — анализ (мудрец) + поглощение/разбор (хищник/вельзевул) + именование + делегирование силы команде.
